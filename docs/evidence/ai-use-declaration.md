# AI-use declaration

AI tools were used as an engineering assistant during Sprint 1 for:

- reviewing SRS, SDS, contracts and traceability for contradictions;
- checking consistency of feature IDs, AC IDs, TEST IDs, routes, statuses and access rules;
- assisting with implementation and test-coverage review;
- organizing release logs, GitHub PR/review evidence and contribution records;
- checking the final documentation against the course deliverable instructions.

The students inspected the repository, reviewed the generated changes, ran the build and test commands, checked failures, and remain responsible for the implementation and every submitted claim. No AI transcript is required or included.
